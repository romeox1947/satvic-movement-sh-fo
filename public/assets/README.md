# Satvic community media

Add photos and videos inside the matching place folder. Supported reel video formats: `.mp4`, `.webm`, `.mov`, `.m4v`.

For a reel, use this filename format: `place_topic_number_creator.handle.mp4`. Example: put `ARAI_hill_1_what.on.more.mp4` in `Experiences/Vetal Tekdi (ARAI Hills)`. The creator handle is everything after the third underscore. Reels appear in the Reels tab and snap vertically as you scroll. A refresh reads newly added files.

Photos can use descriptive names such as `menu.jpg` or `garden.jpg`; they are stored for the matching place.
